# SharedMedia (WoW 3.3.5a WotLK — Cyrillic & Custom Edition)

Расширенный медиа-пак **SharedMedia** для клиента **World of Warcraft 3.3.5a (`Interface: 30300`)** с полной поддержкой кириллицы (`ruRU`) и латиницы (`enUS`/`enGB`).  
Интегрируется со всеми аддонами, использующими библиотеку `LibSharedMedia-3.0`: **ElvUI**, **WeakAuras**, **Details!**, **DBM**, **TellMeWhen**, **MSBT**, **Parrot**, **Quartz**, **Shadowed Unit Frames**, **Grid2**, **VuhDo**, **Plater/TidyPlates** и др.

---

## 📦 Состав сборки (298 медиа-элементов)

| Категория | Количество | Описание |
| :--- | :---: | :--- |
| **Шрифты (`font`)** | **121** | Полная поддержка русского алфавита (все 32 буквы `А–Я`, `а–я`, включая `Ъ`, `Ы`, `Э`) + латиница и цифры |
| **Текстуры полос (`statusbar`)** | **154** | Классические полосы, кастомные игровые/неоновые/карбоновые/сегментированные текстуры, а также паки ToxiUI, Raeli, Bezo и Ferous |
| **Рамки (`border`)** | **16** | RothSquare, Raeli Glow и серия Ferous (1–13) |
| **Фоны (`background`)** | **7** | Bricks, Brushed Metal, Copper, Moo, Overlay Rect, Screen Overlay, Smoke |

## 🛠 Установка

1. Скопируйте папку `SharedMedia` в директорию `Interface\AddOns\` вашего клиента WoW 3.3.5a:
   ```text
   World of Warcraft\Interface\AddOns\SharedMedia\
   ```
2. **Полностью перезапустите клиент игры (`Wow.exe`)**, если он был открыт во время копирования файлов.
3. Выберите нужный шрифт или текстуру полосы в настройках вашего аддона (например, `ElvUI -> Общие -> Медиа`).
